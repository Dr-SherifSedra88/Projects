# Projects

## biology-as-notes-9700

Cambridge International AS Level Biology (9700) revision notes, redesigned and
aligned to the 2025-2027 syllabus.

- `Biology AS Notes (9700) - Dr. Sherif Sedra.pdf` — printable PDF (105 pages)
- `index.html` — printable HTML version (open directly, or view via GitHub Pages)
- `images/` — all 168 embedded diagrams/figures
- `style.css` — stylesheet used by `index.html`

## nutriclinic-pro

NutriClinic Pro — clinical nutrition & patient management platform for a private clinic:
electronic patient records, clinical assessments, automated energy/calorie-target engines,
20 therapeutic diet approaches with plan builder + smart food exchange, patient-aware
copilot (Arabic/English), follow-up management with calorie reassessment, branded/plain
PDF reports, and a bilingual EN/AR interface.

- `index.html` — standalone build: open directly (no build step, no dependencies)
- `css/`, `js/`, `assets/` — application source (vanilla JS, offline-capable)
- `README.md` — run / modify / quality documentation
- `docs/` — production deployment path (PostgreSQL schema, backend & security notes)
