# Projects

## biology-as-notes-9700

Cambridge International AS Level Biology (9700) study notes, rebuilt from the
original CIE notes and aligned to the 2025-2027 syllabus framework.

- `Biology AS Notes (9700) - Dr. Sherif Sedra.pdf` — printable PDF (111 pages,
  full-bleed original cover, watermarked pages, bookmarks, clickable TOC with
  page numbers, page-number footers)
- `index.html` — interactive digital study book (open in any browser; also
  print-ready with the same A4 design)
- `images/` — all original diagrams/figures in their original order
- `style.css` — screen (digital book) + print (A4) styles
- `cover_original.jpg` / `logo_watermark.png` / `logo_black.png` — artwork assets
- `cover_photo.jpeg` — repo cover image

### What's in this revision (September 2026)

- **Rebuilt via OCR extraction** — all 55 source pages passed through OCR and
  were audited against the notes text (page-level completeness check); every
  part of the notes is real, selectable, editable text — figures kept as-is
  in their original order.
- **Original cover kept** from the main notes PDF, plus a new matching back
  cover with the Dr. Sherif M. Sedra logo. The word "revision" removed from
  the subtitle line.
- **Logo watermark** on every content page of the PDF and behind the HTML.
- **Cheerful palette, no green** — warm cream paper, indigo bands, coral and
  amber accents.
- **Interactive HTML** — live topic search with jump-to-section, collapsible
  topics, reading progress bar, sticky Contents/Top navigation, smooth
  scrolling; responsive down to phone widths.
- Text corrections applied throughout (spelling, spacing, numbering).

### Printing

`index.html` is print-ready: A4, full-bleed cover on the first page. For the
best result use the included PDF, or print from Chrome/Edge with background
graphics enabled.
